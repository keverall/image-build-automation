## Description

Phase 1 - Autofix: `ruff check --fix` repairs what it can (unused imports, import sorting, simple style issues). Phase 2 - Verify: `ruff check` re-runs with no fixes so any remaining violations are reported and fail the build. Ruff resolution order: 1. `ruff` on PATH 2. `uv run ruff` (uv-managed environments) 3. `python -m ruff` 4. `python -m pip install ruff` (user scope), then fall back to 3. Directory exclusions are defined in ruff.toml (vendor, generated, bin, scripts/modules). Exit 0 if clean; exit 1 if violations remain or Ruff cannot be made available.
