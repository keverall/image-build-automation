## Description

Executes PowerShell scripts on remote Windows servers using WinRM (WS-Man). Creates a temporary PSSession for the operation and returns results including stdout and any errors encountered during execution.

<a id="parameters"></a>

## Parameters

| Parameter | Description |
|-----------|-------------|
| `-Script` | PowerShell script to execute remotely. |
| `-Server` | Remote server hostname or IP. |
| `-Username` | Username for WinRM authentication. |
| `-Password` | Password for WinRM authentication. |
| `-Transport` | WinRM transport (default: NTLM). |
| `-TimeoutSeconds` | Timeout per command in seconds (default: 300). |
| `-ArgumentList` | Optional arguments passed to the remote script block (which should declare a param() block to receive them). Use this to pass secrets so they travel over the encrypted remoting channel instead of being embedded in the script text. |

<a id="examples"></a>

## Examples

<a id="example-1"></a>

### Example 1

```powershell
$r = Invoke-PowerShellWinRM -Script 'Get-Process' -Server 'srv01.corp.local' -Username 'admin' -Password 'pass'
```
