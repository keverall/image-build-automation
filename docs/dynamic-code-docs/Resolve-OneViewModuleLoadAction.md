## Description

The HPE OneView library refuses to load a second library into one console (HPEOneView.1000.psm1 throws 'CannotLoadMultipleLibraries'). Centralising the decision keeps the rule in one audited place: a loaded module that matches the pinned name (and version, when known) is reused, a conflicting library is refused with an actionable error, and nothing is re-imported blindly.
